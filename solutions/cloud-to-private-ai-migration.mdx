# 从Rainbond Cloud迁移到私有环境：应用模板导出与安装

如果你的 AI 应用已经在 Rainbond Cloud 跑通，可以通过应用快照和应用模板迁移到自己的私有 Rainbond，不需要重新手工创建前端、API、Worker、数据库和缓存等服务。

这条路径适用于 AI 开发生成的业务应用，也适用于 Dify 等多组件 AI Agent 应用。

应用在 Cloud 中部署和验证时，可以从 Claude Code、Codex 使用 RainSkills，也可以在 Rainbond 控制台使用 RainAgent；迁移到私有 Rainbond 后，两种入口仍可继续用于更新、排错和交付验证。

## 在Cloud中完成导出

1. 确认应用中的页面、API 和核心业务路径已经验证通过。
2. 在应用总览或应用版本页面创建快照。
3. 选择快照，填写模板名称和版本，发布到本地组件库。
4. 从发布记录中选择目标版本并导出应用模板包。

模板版本中应写清应用用途、代码版本、主要组件、CPU 架构和安装后需要重新配置的内容。

## 在私有Rainbond中安装

登录自己的 Rainbond，进入：

```text
平台管理 → 应用市场 → 离线导入
```

上传模板包后，从本地组件库选择目标团队并安装。安装完成后检查组件数量、依赖关系、运行状态和访问入口是否符合预期。

## 哪些内容需要单独处理

应用模板主要交付应用组件、依赖关系和版本，下面这些内容需要根据实际环境迁移或重新配置：

| 内容 | 处理方式 |
| --- | --- |
| 数据库业务数据 | 通过数据库备份和恢复迁移 |
| 知识库与上传文件 | 导出后进入私有对象存储或持久化卷 |
| 大模型文件 | 单独导入私有模型仓库并创建实例 |
| 密码、Token和证书 | 在私有环境重新创建，不写入公共模板 |
| 域名与模型API | 替换成私有环境地址 |
